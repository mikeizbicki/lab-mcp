### Part 1A: JSON

Whenever you login to the lambda server, you are greeted with a message like.
```
 ----------------------------------------
< You will be misunderstood by everyone. >
 ----------------------------------------
        \   ^__^
         \  (oo)\_______
            (__)\       )\/\
                ||----w |
                ||     ||
```
These messages are generated by running the command `fortune | cowsay`.
(`fortune` prints a random statement,
and `cowsay` reformats stdin so that it looks like a cow is saying it.)

Our first task today will be to use LLMs to classify these messages as funny or not funny.
The standard trick for converting an LLM into a classifier is to force it to output json,
and *json-schema* files are how we define the structure of the output.

Below is an example json schema for funny/not funny classification.
```
$ cat > funny.json-schema <<'EOF'
{
  "type": "object",
  "properties": {
    "label": { "enum": ["funny", "not_funny"] },
    "confidence": { "type": "number", "minimum": 0, "maximum": 1, "description": "higher is more confident" },
    "explanation": { "type": "string", "description": "1 sentence" }
  },
  "required": ["label", "confidence", "explanation"],
  "additionalProperties": false
}
EOF
```
Every json schema starts with a `"type"` entry that is one of:
1. `"object"` (the json word for dictionary)
1. `"array"` (the json word for list)
1. `"number"`
1. `"string"`
When the type is `"object"`, we must also have the following three other entries:
1. `"properties"`: a dictionary (or more properly in json terminology an object) whose keys are the keys in the final output and values describe.
1. `"required"`: those keys from `"properties"` that the LLM must output
1. `"additionalProperties"`: whether additional keys not present in the `"properties"` object are allowed in the output json.
    It is usually `false`.
    (Also observe that in json we use `false` instead of python's `False`.)

Now using this schema, we can classify the unix jokes as funny or not funny to get a sense of our AI's sense humor.
```
$ fortune | cowsay | tee /dev/stderr | deepseek --schema=funny.json-schema
```

Download this fun meme from the internet

Otherwise, on any terminal you can view an asciified version of the image with
```

```
You can attach images (and other binary files) to the LLM's prompt with the `-a` command,
and so the following will rate the funniness of the gif:
```
$ deepseek -a giphy.gif --schema=funny.json-schema
```

> **Take Away Lesson:**
> You can quickly generate a classifier for any machine learning problem by just writing the appropriate json schema,
> and then calling the LLM.
> This technique automates about 50% of the work that data scientists did at small companies pre-2022.

> **NOTE:**
> Problems installing?
> Fscking backwards compatibility issues.
> `mcp-server-sqlite` depends on `mcp`, which is the standard library for writing MCP servers in python.
> `mcp` introduced a backwards-incompatible change when they went from 1.30.0 -> 2.0.0.
> `mcp` correctly bumped the major version number when introducing a backwards compatible change,
> but `mcp-server-sqlite` incorrectly depends on `mcp >= 1.3` instead of `mcp >= 1.3. < 2`,
> and so your pip command is installing the incompatible version.
> The fix is to first install a version of mcp < 2.0.0 and then install mcp-server-sqlite.
>

### Part 2d: Writing an MCP server

```
$ cat > mcp-server-bash <<'EOF'
#!/usr/bin/env python3
import subprocess
from mcp.server.mcpserver import MCPServer

server = MCPServer("bash")

@server.tool()
def run(command: str) -> str:
    """Run a shell command."""
    r = subprocess.run(command, shell=True, capture_output=True, text=True)
    out = r.stdout + r.stderr
    return out if r.returncode == 0 else f"exit {r.returncode}\n{out}"

server.run()
EOF
$ chmod a+x mcp-server-python
```

```
$ deepseek --mcp=./mcp-server-bash 'what files are in the current folder'
$ deepseek --mcp=./mcp-server-bash 'are there any bugs in my .bashrc?'
```

```
$ deepseek --mcp=./mcp-server-bash 'create a new folder $HOME/new-repo, make it a git repo, and commit a python file that prints the first 100 primes'
```

```
$ deepseek --mcp='--share-net ./mcp-server-bash' "I'm ssh'd into a university server via a vpn.  I want to know what other machines are behind this vpn that I can connect to from here."
```
